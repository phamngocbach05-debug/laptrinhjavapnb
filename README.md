# Quan Ly Tuyen Sinh

Bai tap Java: Quan ly Tuyen sinh - Lap trinh Java huong doi tuong

## Cau truc goi GTS

| File | Mo ta |
|------|-------|
| `IThisinh.java` | Interface dinh nghia cac phuong thuc |
| `Thisinh.java` | Lop doi tuong Thi sinh (SoBD, Hoten, GT, NganhH, TongD) |
| `XLTS.java` | Lop xu ly du lieu, implements IThisinh |
| `GUI_insertTS.java` | Giao dien JFrame quan ly thi sinh |

## Cach chay

1. Mo du an bang IDE (IntelliJ / Eclipse / NetBeans)
2. Chay file `GUI_insertTS.java` (ham `main` nam trong file nay)

## Chuc nang chinh

- Hien thi danh sach thi sinh len JTable
- Them thi sinh moi (SoBD, Ho ten, Gioi tinh, Nganh hoc, Tong diem)
- Xoa thi sinh duoc chon
- Tim kiem theo So bao danh
- Tu dong tinh Hoc bong: Tong diem >= 29 -> "HB"
